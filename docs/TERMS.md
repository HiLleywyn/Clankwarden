# Clankwarden Terms of Service

Clankwarden is a Discord containment and moderation bot. By adding it to a
server or using its commands, the server's administrators and members agree to
these terms. Operators publishing the bot should host this document as their
Terms of Service and pair it with the privacy policy in `PRIVACY.md`.

## What the bot does

Clankwarden provides scammer/bot containment (the `.clank` system), a moderation
command set, an audit log, automatic impersonation (dehoist) handling, and a
setup wizard. It acts only within the servers it is added to, using the Discord
permissions granted at invite time.

## Data

Clankwarden stores the moderation data described in `PRIVACY.md`, scoped per
server. Deletion paths (per-server on removal, per-user via `.modlog forget`,
and the `EVIDENCE_RETENTION_DAYS` / `MOD_LOG_RETENTION_DAYS` retention windows)
are documented there. Your use of the bot is also governed by that policy.
